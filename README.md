# 🥨 Pretzel Rogue: Auto Battler

一款**roguelike 自动战斗**网页游戏——12 职业编队 + 自由阵型 + 分支地图 + 混合变现仿真。浏览器即开即玩，无需安装。

**▶ 在线试玩**：部署后此处替换为 GitHub Pages 链接

## 项目来源

基于两款竞品的深度拆解融合而成（APK 逆向 + 系统还原）：

| 竞品 | 借鉴 | 规避 |
|---|---|---|
| **Tower War**（SayGames，1 亿+下载） | 激励广告点位体系、双货币分层、×2/×3 结算翻倍 | 广告时间>游玩时间的差评根因（8% 红线频控） |
| **Despot's Game**（tinyBuild） | 职业构筑深度、肉鸽惩罚与变异系统 | 单局过长无法承载高频广告（战斗切至 20-40s） |

## 核心系统

- **战斗**：3×5 自由阵型布防、2D 寻敌自动战斗、职业能量技、Boss 召唤/狂暴
- **双轨成长**：局内击杀/治疗升级（结算清零）+ 局外金币永久养成（带入战斗）
- **经济**：铜币（局内）/ 金币（永久）/ 水晶（硬通货）三层货币 + 金币兑铜币回路
- **广告仿真**：6 类激励点位独立日上限 + 全局频控 + 低频插屏，含"免广告"开关
- **外围**：分支地图（每层 2 选 1）、事件房、精英房、Brawl 镜像对决、金宝箱开局增益

## 技术栈

纯原生 HTML/CSS/JavaScript 单文件实现，无框架无构建；美术资源采用 [Kenney Tiny Dungeon](https://kenney.nl/assets/tiny-dungeon)（CC0 公共领域）。

## 本地运行

直接双击 `index.html`，或任意静态服务器指向本目录。存档保存在浏览器 localStorage。
